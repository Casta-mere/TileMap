🗺️ TileMap

功能强大的瓦片地图下载工具

📖 项目介绍

TileMap 是一个功能强大的瓦片地图下载工具，支持从 Google Maps 和 OpenStreetMap 下载地图瓦片，并自动拼接成完整的大图。提供友好的 Web 界面，可视化选择下载区域。

📢 注意： 这是一个需要在本地运行的 Flask 应用程序。本页面仅作为项目文档和演示使用。
📦 GitHub 仓库 🚀 快速开始

✨ 功能特性

🌐 Web 界面

提供友好的 Web 界面，可视化选择下载区域

🗺️ 区域选择

支持预设区域（省/市/区）和自定义坐标选择

📊 多层级下载

可以选择下载多个缩放层级（0-19）

🎨 多种样式

支持标准、卫星、混合、地形、深色等多种地图样式

🧩 自动拼接

自动将最高层级的瓦片拼接成完整大图

⚡ 多线程下载

使用多线程加速下载过程，支持断点续传

🚀 快速开始

1. 克隆仓库

git clone https://github.com/Casta-mere/TileMap.git
cd TileMap

2. 安装依赖

pip install -r requirements.txt

3. 启动 Web 服务器

python web_app.py

4. 打开浏览器

在浏览器中访问：http://localhost:5000

💡 提示： 层级越高，图片越详细，但下载的瓦片数量呈指数增长。建议从较小的区域和较低的层级开始测试。

🐍 Python 模块使用

除了 Web 界面，您也可以直接使用 Python 模块：

from tile_downloader import TileDownloader

# 创建下载器
downloader = TileDownloader(output_dir='tiles', style='standard')

# 定义下载区域
lat1, lon1 = 39.92, 116.38 # 天安门区域
lat2, lon2 = 39.88, 116.42

# 下载多个缩放层级
results = downloader.download_area(
lat1, lon1, lat2, lon2,
zoom_levels=[10, 11, 12, 13]
)

# 拼接最高层级的瓦片
stitched_path = downloader.stitch_tiles(13)
print(f"拼接图片保存在: {stitched_path}")
